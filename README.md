# Happy Deco - Sitio institucional

Sitio principal de Happy Deco, creado como proyecto independiente del catálogo de vidrieras.

## Requisitos

- Node.js 22.13 o superior
- npm

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí la URL local indicada por la terminal.

## Validación

```bash
npm run build
npm run lint
```

## Despliegue en Netlify

El proyecto es compatible con Netlify. Para generar una vista previa:

```bash
npx netlify deploy
```

Para publicar una versión aprobada:

```bash
npx netlify deploy --prod
```
